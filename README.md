# GestorServiços - Guia para Gerar o APK do Android

Este pacote contém todos os arquivos necessários para transformar o seu sistema **GestorServiços** em um **Aplicativo Nativo Android (.apk)**.

## 🚀 Como gerar o APK em 2 minutos (Sem complicações):

Existem duas formas muito simples e gratuitas de transformar este site em um aplicativo Android instalado no seu celular:

### Método 1: Usando o PWABuilder (Recomendado e Gratuito)
1. Hospede os arquivos (`index.html`, `manifest.json`, etc.) em um serviço gratuito como **GitHub Pages**, **Netlify** ou **Vercel**.
2. Acesse o site oficial: [https://www.pwabuilder.com/](https://www.pwabuilder.com/)
3. Cole o link do seu site hospedado e clique em **"Start"**.
4. O site analisará o seu app e mostrará um card para **"Generate Android App"**.
5. Clique em gerar, baixe o arquivo `.apk` ou o pacote para a Google Play Store e instale no seu celular Android!

### Método 2: Usando o AppMaker / WebView App Wrapper (No Celular)
1. Baixe na Google Play Store um aplicativo gratuito de conversão de site para APK (como **"HTML to APK App Generator"** ou **"WebViewGold"**).
2. Aponte o app para o arquivo `index.html` ou para o seu link hospedado.
3. Defina o nome **GestorServiços**, adicione um ícone e clique em compilar o APK.

Pronto! Agora você tem um aplicativo profissional instalado direto na gaveta de aplicativos do seu Android.
